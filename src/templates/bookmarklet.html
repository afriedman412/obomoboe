Didn't work? Step by step
  1. Show your bookmarks bar. Chrome, Edge, Brave or Firefox: ⌘⇧B on a Mac, Ctrl+Shift+B on Windows. Safari: View → Show Favorites Bar.
  2. Drag the button onto the bar. Use the install page in your web browser — the obomoboe window has no bookmarks bar to drag it to.
  3. Click it on an article. Wait for the page to finish loading, then click it. A small window says Saving…, then Saved, and closes itself. If your browser asks about pop-ups, allow them for that site.

Still can't drag it? Make the bookmark by hand: copy the code below, bookmark any page, then edit that bookmark — name it Save to obomoboe and paste the code in as its address.
